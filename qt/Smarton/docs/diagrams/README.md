# Diagrams

Commit the **source**, not only the export. A PNG nobody can edit is a dead
diagram.

- `*.mmd`    — Mermaid, renders natively on GitHub
- `*.drawio` — draw.io / diagrams.net
- `*.svg`    — exported for embedding

Minimum set for any project: a component diagram (the layer stack), a sequence
diagram (the most important interaction), and a state diagram if navigation is
non-trivial.
